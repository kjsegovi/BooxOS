## Fixed today
1. **Ghosting:** idle auto-clean in SurfaceFlinger (`tools/build-host/patches/frameworks_native-0001-epdc-update-list.patch`, generator `mkpatch-epdc.py`).
   - CompositionEngine publishes each frame's dirty area. HidlComposer adds up what partial updates changed.
   - Once the screen has been quiet for `epdc_idle_ms` and that total reaches `epdc_clean_pct` % of the screen, it asks SurfaceFlinger for one more frame (debug code 1004, with the interface token) and sends it with `epdc_full_mode`.
   - Defaults: mode 5, full 34, clean_pct 500, idle_ms 1000.
2. **Touch never worked:**
   - The Onyx istaric driver leaves the touch IRQ off after probe (`onyx_tp_irq_set ... Off`; the IRQ count stays at 1).
   - Resetting the controller through `/sys/devices/platform/soc/988000.i2c/i2c-2/2-0055/reset` turns it back on.
   - `device/onyx/GoColor7_2/init/init.booxos.rc` runs that reset at boot_completed. It runs from a oneshot service in the `su` domain, because init gets `avc: denied` on the generic sysfs label. `su` exists only in userdebug builds, so this **needs real sepolicy before a user build**.
3. **Screen kept "sleeping":**
   - The swipe lock screen put the display back to sleep after 10 s, which you can't see on e-ink.
   - Fix: `ro.lockscreen.disable.default=true`.

## Next: refresh tuning (user feedback)
"Flashing is too often, but there is also ghosting build-up."

A single area threshold can't satisfy both. Ideas:
